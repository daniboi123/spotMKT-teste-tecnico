## ✅ Funcionalidades

### 📌 Tela 1: Login
- Interface de login simples.
- Verificação de credenciais diretamente no frontend.
- **Credenciais fixas para acesso:**
  - Usuário: `spotmkt`
  - Senha: `123`

### 📊 Tela 2: Dashboard (Painel Principal)
- Layout ilustrativo para painel de cliente de uma agência de marketing digital.
- Informações fictícias para:
  - Métricas de campanhas
  - Insights
  - Solicitação de demandas
  - Calendário de ações
  - Notificações
  - Histórico de ações
  - Configurações e dados do usuário
- Interface responsiva para desktop e dispositivos móveis.
- Navegação fictícia, não funcional (foco no layout e usabilidade).
